# Arkhiv — текстовий редактор

## Структура файлів для GitHub

```
index.html      ← головний файл
style.css       ← стилі
app.js          ← логіка
manifest.json   ← PWA конфіг
sw.js           ← Service Worker (офлайн)
icon-192.png    ← іконка PWA
icon-512.png    ← іконка PWA (велика)
icon-180.png    ← іконка для iOS
favicon.png     ← favicon браузера
```

## Публікація на GitHub Pages

1. Створи репозиторій (наприклад `tree-editor`)
2. Завантаж ВСІ файли вище
3. Settings → Pages → Branch: `main`, folder: `/ (root)` → Save
4. Через ~2 хв сайт буде на `https://<username>.github.io/tree-editor/`

## Встановлення як PWA

### Android (Chrome)
- Відкрий сайт → меню ⋮ → "Встановити застосунок"

### iOS (Safari)
- Відкрий сайт → кнопка Поділитись → "На екран Додому"

### ПК (Chrome/Edge)
- Відкрий сайт → іконка ⊕ в адресному рядку → "Встановити"

## Firebase

1. console.firebase.google.com → твій проєкт
2. Project Settings → Your apps → </> → скопіюй конфіг
3. В Arkhiv натисни ☁ → встав JSON → Підключити

## Клавіатурні скорочення

| Ctrl+S       | Зберегти          |
| Ctrl+N       | Нова сторінка     |
| Ctrl+Shift+P | Markdown Preview  |

## Історія версій

7.1.0, Базова версія редактора: дерево сторінок, синхронізація через Firebase, формати Текст/Markdown/Форматований, перегляд, експорт у PDF, емодзі-панель, офлайн-режим (PWA).
7.2.0, Додано кнопки розкривного тексту для Markdown (`<details>`/`<summary>`) на верхній панелі та відображення версії програми у верхній панелі.
7.3.0, Заголовок сторінки тепер форматується як markdown у режимі перегляду (###, **, *, код, посилання).
7.3.1, Виправлено вигляд заголовків (###) у прев'ю назви сторінки — тепер синій колір і збільшений шрифт, як і в звичайному тексті.
7.3.2, Виправлено рендеринг markdown (###, **...**) усередині тегів <details>/<summary> у тексті сторінки — раніше він взагалі не парсився через особливість CommonMark; виправлено також відсутність рендеру заголовків у назві сторінки (тег заголовка відкидався замість застосування стилю).
7.3.3, Стрілка розкривного тексту (<summary>) тепер розташована під заголовком/текстом, а не над ним.
7.3.4, Стрілку розкривного тексту повернуто зліва від заголовка/тексту; нативна браузерна стрілка тепер повністю прихована в усіх браузерах.
7.3.5, Виправлено переніс стрілки на окремий рядок над заголовком: заголовок (###) усередині <summary> тепер не створює новий блок, тому стрілка й текст завжди в одному рядку.
7.3.6, Кнопка "Розгорнути" тепер відкриває/закриває всі розкривні блоки (<details>) на сторінці одночасно, а не по черзі. Виправлено заголовок сторінки: текст типу "1. DC+ідеальне" більше не перетворюється на нумерований список (кружечок замість "1."), а відображається як звичайний текст.
7.4.0, Верхню панель перероблено у вертикальну колонку зліва (одним стовпчиком кнопок): спочатку кнопки дерева, далі кнопки редагування/інші кнопки, знизу — версія програми, назва програми та e-mail користувача вертикальним текстом (верх букв вліво). Це вирішує проблему втрати панелі при прокручуванні сторінки, оскільки колонка тепер займає всю висоту вікна поруч із деревом і редактором, а не "плаває" над контентом.
7.5.0, Додано підсвітку синтаксису в режимі редагування (plain/markdown): html-теги, ### на початку рядка (будь-якого рівня) та **жирний текст** тепер виділяються різними кольорами прямо під час набору. Технічно реалізовано через прозору textarea з кольоровою підкладкою під нею (сам textarea колірувати текст по символах не вміє). Також для textarea редактора вимкнено autocorrect/autocapitalize/spellcheck/autocomplete — це має усунути баг на планшетах, коли при швидкому наборі "###" третій символ "#" не вводився, а вже введені "##" зсувались вправо (наслідок роботи вбудованого автовиправлення/передбачення клавіатури, яке підмінювало щойно введені символи). Якщо після цього оновлення проблема лишиться на конкретному пристрої — це вже особливість конкретної віртуальної клавіатури (наприклад, фірмової клавіатури виробника планшета), а не сторінки, і варто спробувати іншу клавіатуру (наприклад Gboard).
